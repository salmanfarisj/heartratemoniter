# PulseX

A Flutter heart-rate monitor & activity tracker with a custom PulseX
logo (heart + ECG mark, gradient cyan→blue), live Bluetooth HR streaming,
zone tracking, history charts, and CSV export.

> Rebranded from the original `heartratemoniter` Flutter starter —
> the app id, bundle, and UI strings now all read **PulseX**.
